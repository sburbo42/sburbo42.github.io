Pokédex Team Builder



The Pokédex Team Builder is a JavaScript app that pulls live data from the PokéAPI. Search for any Pokémon to see its image, type, and base stats, then build a team of up to six. Your team is saved in the browser, so it's still there the next time you visit.

I built this project to practice working with APIs, handling data, and using Git branches for each new feature. See it in action below:

TRY IT OUT

Open the live site here, or view the code on GitHub.

BUILT WITH

HTML, CSS (Flexbox), JavaScript (Fetch API, async/await, localStorage), and the PokéAPI

WHAT I LEARNED

  • How to request data from an API with fetch, and why async and await are needed when waiting on a response from the internet.
  • Handling errors by checking response.ok and using return to stop a function early.
  • Saving and loading data with localStorage, and converting it with JSON.stringify and JSON.parse.
  • Working with Git branches for each new feature, then merging them into main.
  • Deploying a site with GitHub Pages.
